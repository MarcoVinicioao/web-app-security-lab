# Web Application Security Lab

Proyecto educativo para aprender los fundamentos del desarrollo y la seguridad de aplicaciones web.

## Objetivos

* Configurar un servidor web.
* Crear una interfaz HTML.
* Diseñar la aplicación utilizando CSS.
* Añadir funcionalidad con JavaScript.
* Desarrollar un backend con Python y Flask.
* Conectar la aplicación a una base de datos SQLite.
* Crear y consumir una API.
* Identificar vulnerabilidades comunes en aplicaciones web.
* Corregir las vulnerabilidades encontradas.
* Documentar el proceso de desarrollo y seguridad.

## Tecnologías

* HTML5
* CSS3
* JavaScript
* Python
* Flask
* SQLite
* Nginx
* Git
